                That is the default; Paragraph Spacing later in this block changes it.

                Someone will spot the lonely ``2.''.

                \texttt{Section\textasciitilde 2}, \texttt{Dr.\textasciitilde Watson}, \texttt{10\textasciitilde K}.
                It comes back in block 4, as the space in \texttt{Fig.\textasciitilde\textbackslash ref}.

                \tcbinputlst[fontsize=\footnotesize]{listings/02-forced-break.tex}
            }
            \begin{alertblock}<2->{Forced Line Breaks}
                \code|\\| ends a line, not a paragraph.
                Only use it in tables and math.
            \end{alertblock}
        \end{column}
    \end{columns}
    \note{%
        The \texttt{\textbackslash\textbackslash} warning is the most valuable thing in block 2.
        \begin{itemize}
            \item One sentence per line: \texttt{git diff} then shows the sentence that changed, not the paragraph.
                The template is written this way.
            \item Every beginner reaches for \texttt{\textbackslash\textbackslash} because it feels like Word's Enter key.
                It is wrong in a way that only shows once the document is long enough to reflow.
            \item Name the symptom, so they recognise it later:
                \texttt{Underfull \textbackslash hbox (badness 10000)} in the log,
                and a paragraph whose last line is stretched across the full width.
        \end{itemize}
    }
\end{frame}

        \item<4-| handout:1> Usually already installed (MiKTeX fetches it on first use)
        \item<5-| handout:1> Documentation: \texttt{ctan.org/pkg/<name>}
    \end{itemize}
    \note{%
        Same shape as \texttt{\textbackslash documentclass}: a command with an optional and a mandatory argument.
        Let them notice that themselves if they can.
        \begin{itemize}
            \item CTAN has about 6\,000 packages.
                That always gets a reaction; the follow-up is that they will personally use about eight of them.
            \item TeX Live, MacTeX and Overleaf have all of them.
                MiKTeX asks to install a missing package the first time a document loads it.
            \item Package order rarely matters.
                The one exception (\texttt{hyperref} goes last) comes up in block 4.
        \end{itemize}
    }
\end{frame}

    \note{%
        The first real use of the preamble.
        \begin{itemize}
            \item First click: the default.
                The first paragraph after a heading is not indented, every later one is.
                Fine for a novel, unusual for a lab report.
            \item Second click: the fix most beginners find, \texttt{\textbackslash noindent} everywhere.
                It removes the indent, but the paragraphs now run into each other,
                and missing one \texttt{\textbackslash noindent} looks broken.
            \item Third click: one line in the preamble.
                No indent, a gap between paragraphs, and the document itself is back to plain paragraphs.
                Undo it by deleting one line.
            \item If you find yourself repeating a command, look for a package.
            \item A blank line between paragraphs is common in German-speaking reports,
                so for a lot of their coursework \texttt{parskip} is a good choice.
        \end{itemize}
    }
\end{frame}
