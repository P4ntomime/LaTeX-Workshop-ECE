                \item<3-> \code|[htbp]|: where it may go
                    \begin{itemize}
                        \item \code|h| here
                        \item \code|t| top of a page
                        \item \code|b| bottom of a page
                        \item \code|p| on its own page
                    \end{itemize}
            \end{itemize}
        \end{column}
    \end{columns}
    \vfill
    \begin{exampleblock}<4->{Placement}
        A wish list, tried in order.
        Let \LaTeX{} decide.
    \end{exampleblock}
    \note{%
        \begin{itemize}
            \item The \texttt{tabular} is now inside a \texttt{table}.
                \texttt{table} is the float, \texttt{tabular} is the grid of cells; beginners mix the two names up.
            \item \texttt{[htbp]} is a wish list, tried in order.
                Fighting float placement is a huge time sink; do not start.
            \item ``My table moved to the next page'' is not a bug.
                It is what floats are for, and the reason they get a number:
                the text says ``Table 1'' instead of ``the table below''.
            \item \texttt{[H]} from the \texttt{float} package: say it exists, say it is a last resort, move on.
                Taught as normal, it gives documents full of half-empty pages.
            \item The 2025 deck said \texttt{!} ``forces'' placement.
                It does not, it only relaxes \LaTeX{}'s internal limits.
                \texttt{[H]} is the one that forces.
        \end{itemize}
    }
\end{frame}

                Without a caption there is no number, and nothing to refer to.
            \item \texttt{\textbackslash label} attaches to the last number that was created.
                Before \texttt{\textbackslash caption}, that is the section number,
                so a reference to the table shows the section number instead.
                It fails silently: no error, just a wrong number.
                Say it twice.
            \item What the name is for comes in a few slides, under cross-references.
            \item The output of this float is the first click of the next slide.
        \end{itemize}
    }

    \note{%
        \texttt{\textbackslash includegraphics} on its own already works, anywhere in the text.
        The next slide puts it in a float, like the table.
        \begin{itemize}
            \item \texttt{graphicx}, with an x.
                There is an older \texttt{graphics} package with a clumsier syntax;
                they will never need it.
            \item \texttt{0.8\textbackslash textwidth} survives a change of margins or paper size.
                Fixed sizes like \texttt{width=12cm} do not.
            \item The template keeps all images in \texttt{figures/}.
                Forward slashes, also on Windows.
                Avoid spaces in file names.
            \item The extension: \LaTeX{} would find the file without it,
                but \texttt{figures/} might hold \texttt{cooling-curves.pdf} next to the
                \texttt{cooling-curves.tex} or \texttt{.py} that made it.
                Written out, there is no doubt which one is meant.
            \item \texttt{pdflatex} cannot read SVG.
                Export vector graphics (plots, diagrams) as PDF and they stay sharp at any zoom.
                Photos: JPG. Screenshots: PNG.
        \end{itemize}
    }
\end{frame}

\begin{frame}[fragile]
    \frametitle{Labels}
    \vfill
    \tcbinputlst[fontsize=\footnotesize, highlightlines={1,3}]{listings/04-labels.tex}
    \vfill
    \begin{itemize}
        \item<2-> Anything numbered, any name
        \item<3-> Naming convention:
            \begin{itemize}
                \item \code|sec:| sections
                \item \code|eq:| equations
                \item \code|fig:| figures
                \item \code|tab:| tables
            \end{itemize}
    \end{itemize}
    \vfill
    \begin{alertblock}<4->{\texttt{\textbackslash label}}
        After \code|\caption|, on the same line as \code|\section|.
    \end{alertblock}
    \vfill
    \note{%
        \begin{itemize}
            \item The equation is the cooling law from block 3.
                Block 3 promised the way to refer to it: this is it.
            \item Sections, equations, tables and figures:
                all of them get their number from \LaTeX{}, so all of them can be labelled.
            \item The prefixes are not required, \LaTeX{} ignores them.
                They make a long list of labels readable,
                and the editor's autocompletion groups them.
            \item A paragraph break between \texttt{\textbackslash section} and \texttt{\textbackslash label}
                can make \texttt{\textbackslash pageref} point at the wrong page.
                Their template has done it this way since block 1.
            \item Labels must be unique.
                A duplicate gives the warning \texttt{Label `\ldots' multiply defined}.
        \end{itemize}
    }
\end{frame}

% Anatomy of a .bib entry, like Commands and Environments in block 1.
% The code is written here (not read from listings/references.bib),
% because the \tikzmark's need escapeinside: keep it in sync with the
% first entry of references.bib.
% Marks: k9 at the end of the first line (after the comma), f0 at the start
% of the first field, f1 at the start of the last one.
% An escape before or inside the first entry name makes Pygments' BibTeX
% lexer treat the whole entry as a comment (no highlighting), so the marks
% around the entry type (t1/t2) and the key (k1/k2) are placed back from k9
% by counting characters: the code font is monospaced.
% In "@book{halliday2018," @ is column 0, book columns 1 to 4, { column 5,
% the key columns 6 to 17, the comma column 18; k9 sits at column 19.
\newlength{\bibcharwd}

                @book{halliday2018,|\tikzmark{k9}|
                    |\tikzmark{f0}|author    = {Halliday, David and

                                 Walker, Jearl},
                    title     = {Fundamentals of Physics},
                    edition   = {11},
                    publisher = {Wiley},
                    |\tikzmark{f1}|year      = {2018},
                }
            \end{minted}
        \end{minipage}
    \end{center}
    \vfill
    \uncover<5->{%
        \begin{center}
            \color{black!60}
            In \texttt{references.bib}, next to the \texttt{.tex} file
        \end{center}
    }
    \vfill
    \settowidth{\bibcharwd}{\normalsize\ttfamily 0}%
    \begin{tikzpicture}[remember picture, overlay]
        \tikzmark{t1}{([xshift=-18\bibcharwd]pic cs:k9)}
        \tikzmark{t2}{([xshift=-14\bibcharwd]pic cs:k9)}
        \tikzmark{k1}{([xshift=-13\bibcharwd]pic cs:k9)}
        \tikzmark{k2}{([xshift=-1\bibcharwd]pic cs:k9)}
        \only<2-| handout:1>{\annotateabove[-.6cm]{t1}{t2}{2mm}{Entry type}}
        \only<3-| handout:1>{\annotateabove[.4cm]{k1}{k2}{2mm}{Key: your choice}}
        % Overlay 4: a bracket on the left, from the first to the last field.
        \only<4-| handout:1>{%
            \coordinate (top) at ([xshift=-3mm, yshift=3.6mm]pic cs:f0);
            \coordinate (bottom) at ([xshift=-3mm, yshift=-1.4mm]pic cs:f1);
            \draw[annotation] ([xshift=\annoarm]top) -- (top) -- (bottom) -- ([xshift=\annoarm]bottom);
            \node[annotation, anchor=east, font=\normalsize]
                at ($(top)!.5!(bottom) + (-2mm,0)$) {Fields};
        }
    \end{tikzpicture}
    \note{%
        Every source is written down once, in its own file next to the document.
        \begin{itemize}
            \item Entry type: \texttt{@book}, \texttt{@article}, \texttt{@online}, \texttt{@thesis}, \ldots{}
                The handout has the common ones and the fields each one needs.
            \item The key is what they type in the document.
                It is theirs to choose; author plus year is the usual pattern.
            \item Fields: \texttt{name = \{value\}}, separated by commas.
                How to write the names is on the next slide.
            \item The format is called Bib\TeX{}, after the old program.
                It is still the format everything exports.
        \end{itemize}
    }
\end{frame}

            \onslide<1->\code|Halliday, David|                     & \onslide<1->{\color{black!60}family, given} \\
            \onslide<2->\code|David Halliday|                      & \onslide<2->{\color{black!60}also works} \\
            \onslide<3->\code|Halliday, David and Resnick, Robert| & \onslide<3->{\color{black!60}several: \code|and|} \\
            \onslide<4->\code|Halliday, David and others|          & \onslide<4->{\color{black!60}``et al.''} \\
            \onslide<5->\code|{{World Health Organization}}|       & \onslide<5->{\color{black!60}organisation: one name} \\
            \bottomrule
        \end{tabular}
    \end{center}
    \note{%
        Bib\TeX{} splits every name into parts (given, family, and a few more),
        and the style decides how to put them back together.
        \begin{itemize}
            \item With a comma, everything before it is the family name: \texttt{Halliday, David}.
                Without a comma, the last word is: \texttt{David Halliday}.
                Both give the same result; exports use the comma form.
            \item Names are separated by \texttt{and}, never by commas.
                \texttt{Halliday, David, Resnick, Robert} is read as one strange name.
                This is the mistake they will actually make when typing an entry by hand.
            \item \texttt{and others} prints ``et al.'' for long author lists.
            \item Prefixes like ``van'' or ``von'' are recognised because they are lower case:
                \texttt{van Beethoven, Ludwig} keeps ``van'' with the family name.
            \item An organisation needs the extra braces, otherwise its last word is taken as the family name.
                An example comes after Citation Styles, where it becomes visible.
            \item Braces also protect capitals in titles, for styles that change titles to sentence case
                (\texttt{apa}, for example): \texttt{title = \{Cooling of \{DNA\} Samples\}}.
                The standard \texttt{biblatex} styles leave titles as they are.
                Handout.
        \end{itemize}
    }
\end{frame}

            \color{black!60}
            Overleaf and \texttt{latexmk} run \texttt{biber} for you
        \end{center}

    \vfill
    \note{%
        Someone will ask, because the names sound like two competing tools.
        They are two halves of one setup.
        \begin{itemize}
            \item \texttt{biber} runs between two \LaTeX{} runs:
                \LaTeX{} writes down which keys were cited,
                \texttt{biber} looks them up in the \texttt{.bib} file and sorts them,
                and the next \LaTeX{} run sets the result.
            \item Overleaf and \texttt{latexmk} notice when this is needed.
                By hand: \texttt{pdflatex}, \texttt{biber}, \texttt{pdflatex}, \texttt{pdflatex}.
            \item \texttt{biblatex} can also use the old \texttt{bibtex} program (\texttt{backend=bibtex}),
                with fewer features and trouble with umlauts.
            \item Older tutorials use a different setup altogether:
                \texttt{natbib} or \texttt{\textbackslash bibliographystyle} with the \texttt{bibtex} program.
                It still works, but if they find a 2008 tutorial: this is the newer way.
        \end{itemize}
    }
\end{frame}
