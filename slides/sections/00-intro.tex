\begin{frame}
    \frametitle{What \LaTeX{} actually is}
    \begin{columns}[t, onlytextwidth]
        \begin{column}{.45\textwidth}
            {\Large\bfseries A word processor\par}
            \smallskip
            You make it \textbf{look} right.
            \begin{itemize}
                \item<2-> Select the heading, set 16\,pt bold
                \item<3-> Do it again on the next heading
                \item<4-> Hope they match
                \item<5-> The document is what you see
            \end{itemize}
        \end{column}
        \begin{column}{.45\textwidth}
            {\Large\bfseries \LaTeX{}\par}
            \smallskip
            You say what things \textbf{are}.
            \begin{itemize}
                \item<2-> Mark the heading as a heading
                \item<3-> Mark the next one as a heading
                \item<4-> They match, because nobody chose
                \item<5-> The document is what you \emph{meant}
            \end{itemize}
        \end{column}
    \end{columns}
    \note{%
        \begin{itemize}
            \item The point: you give up control of the look, and get structure and consistency back.
            \item The whole philosophy of the workshop, in 90 seconds.
                Resist the urge to expand it.
            \item ``So it's like Markdown?'' Yes, same idea, much older and much more powerful.
            \item Do not get drawn into Word vs.\ \LaTeX{}.
                ``We'll see what it buys you in about ten minutes.''
                The table of contents in block 1 makes the case better than you can.
        \end{itemize}
    }
\end{frame}

            \begin{enumerate}

                \item New Project, then Upload Project
                \item Drop in the template zip
                \item Open \texttt{workshop.tex}, hit \textbf{Recompile}
            \end{enumerate}
        \end{column}
        \begin{column}{.5\textwidth}
            {\Large\bfseries Later: on your own machine\par}
            \medskip
            \begin{tabular}{@{}lll@{}}
                \toprule
                & \textbf{Install} & \textbf{Edit in} \\
                \midrule
                Windows & \hologo{MiKTeX} & VS Code, TeXstudio \\
                macOS   & Mac\TeX{}       & TeXShop, VS Code \\
                Linux   & \TeX{} Live     & VS Code, TeXstudio \\
                \bottomrule
            \end{tabular}

            \bigskip
            Compile with:
            \begin{tcolorbox}[codebg]
                \mintinline{bash}{latexmk -pdf workshop.tex}
            \end{tcolorbox}
        \end{column}
    \end{columns}
    \note{%
        Two minutes, hard limit.
        Do not demo an installation.
        \begin{itemize}
            \item Overleaf today means the same setup for everyone,
                so every problem today is a \LaTeX{} problem.
            \item This slide exists so that nobody spends the workshop installing software,
                and so that people who want a local setup have the names written down.
            \item \texttt{latexmk} matters more than it looks:
                it is why they never have to count compilation passes.
        \end{itemize}
    }
\end{frame}
